**1. Missing `disconnectedCallback` in `slide-page.js`**

This is a memory leak waiting to happen. The component doesn't clean up.

disconnectedCallback() {

**2. `slide-deck.js` — Potential Memory Leak Pattern**

The touch event listeners are attached without being tracked for cleanup:

```javascript
// Current
this.addEventListener('touchstart', (e) => { ... }, { passive: true });
this.addEventListener('touchend', (e) => { ... }, { passive: true });

// Issue: These are anonymous functions - can't be removed in disconnectedCallback
```

**Fix:**
```javascript
constructor() {
    super();
    // Bind handlers so they can be removed
    this.handleTouchStart = this.handleTouchStart.bind(this);
    this.handleTouchEnd = this.handleTouchEnd.bind(this);
}

setupEventListeners() {
    // ... keyboard/hash listeners (already bound) ...
    this.addEventListener('touchstart', this.handleTouchStart, { passive: true });
    this.addEventListener('touchend', this.handleTouchEnd, { passive: true });
}

cleanup() {
    document.removeEventListener('keydown', this.handleKeyDown);
    window.removeEventListener('hashchange', this.handleHashChange);
    this.removeEventListener('touchstart', this.handleTouchStart);
    this.removeEventListener('touchend', this.handleTouchEnd);
}
```

**3. `slide-page.js` — Monolithic Layout Renderers**

The component has ~15 render methods all in one file (~350+ lines). This makes surgical overrides harder.

**Current:**

renderBHTitle(data) { ... }

// ... 12 more layouts
